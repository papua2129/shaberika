# シャベリカ

[アプリを開く](https://papua2129.github.io/shaberika/) · [GitHubリポジトリ](https://github.com/papua2129/shaberika)

**聞いて、聴いて、訊いて。** 小学4年生を中心に、2〜6人で友達の話を聴き、対話をつなぐWebアプリ。ログイン・得点・勝敗はありません。

## 機能

- 全30テーマを、端末のローカル日付ごとに重複なしで公平に抽選（Web Cryptoの棄却法）
- パスしたテーマも当日は再登場しない。30件で完了画面
- 対話ヒント、一時停止・再開、動きの停止、prefers-reduced-motion対応
- 日別記録、月カレンダー、最近7日間の棒グラフ、テーマ別回数
- 選択中・対話中のテーマを含めた保存・復元、日付切替、二重記録防止
- キーボード対応、390pxから電子黒板までのレスポンシブ表示

## ローカル起動・テスト・ビルド

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview -- --port 5173
```

`src/core.ts` に日付、抽選、復元、記録の純粋ロジックを分離しています。`npm test` はNode標準テストランナーによる8件のテストです。

`tests/browser-smoke.js` はPlaywright CLIの `run-code` 用の再現可能なブラウザ検証です。専用のテストブラウザで実行してください。このスクリプトは **localhost:5173 のテスト用localStorageを初期化します**。公開サイトでの既存記録には使用しないでください。

```sh
npx @playwright/cli --session shaberika open http://127.0.0.1:5173/
npx @playwright/cli --session shaberika run-code "$(cat tests/browser-smoke.js)"
```

検証内容: 空の記録、キーボード操作、保存復元、一時停止・再開、モーション停止、reduced-motion、1920×1080 / 1366×768 / 1280×720 / 390×844、ヒントの非重複、終了記録、削除確認のキャンセル、全30件消化、翌日切替、破損データ復旧。スクリーンショットは `output/playwright/`（Git対象外）に保存します。

## GitHub Pagesへの公開

1. このフォルダを公開リポジトリのルートとして `main` にpush。
2. GitHubのSettings → Pages → Build and deploymentで **GitHub Actions** を選択。
3. `.github/workflows/pages.yml` が依存関係の取得、テスト、ビルド、Pagesデプロイを実行。
4. Actionsの成功と表示された公開URLを確認。

Viteの `base: './'` とハッシュルーティング（`#home` / `#roulette` / `#talk` / `#records` / `#help`）で、リポジトリ名に依存せずサブパス配信と再読み込みに対応します。サーバーや秘密鍵は不要です。

## 保存・プライバシー

localStorageキーは `shaberika-v1`、スキーマバージョンは1です。保存対象は端末日付、使用済みテーマ、進行中セッション、完了したテーマIDのみ。名前、音声、会話内容は収集しません。Cookie、外部フォント、解析・トラッカー、外部APIは使いません。ホスティング側の通常のアクセスログはホスティングサービスの管理範囲です。

端末・ブラウザ間で同期しません。ブラウザデータ削除、プライベートモード終了などで記録を失う場合があります。保存が禁止・容量不足の場合は通知し、その画面内では動作を続けます。未知のバージョンや不正な保存値は、安全に初期化して通知します。手動の全削除には確認が必要です。

日付が変わると抽選状況と未完了の対話だけをリセットし、完了済み記録は保持します。時計・タイムゾーンを変更すると、その端末設定に従います。二重計上はセッションIDで防止します。同時タブでの競合は完全には防げないため、**1端末・1タブでの利用を推奨**。他タブの保存変更は反映します。

## デザイン・ライセンス

ネイビー、アンティークゴールド、深い赤を用いたオリジナルの探偵事務所。事件ファイル、手帳、封蝋、虫眼鏡はCSSと自作SVGで表現しています。既存作品のキャラクター・衣装・ロゴ・画像は使用していません。
